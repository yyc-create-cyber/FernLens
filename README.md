# FernLens — 基于 PySide6 + NumPy + OpenCV 的 Lightroom 风格照片调色器

一个纯本地运行的 Windows 照片调色应用：所有调整**实时预览**，处理在后台线程完成，
拖动滑块时处理降采样图（最长边 1200px），松手后自动处理全图。

---

## 1. 快速开始

```bat
run.bat                 :: 自动建虚拟环境 + 装依赖 + 启动
```

或手动：

```bash
pip install -r requirements.txt
python main.py                      # 也可把图片路径作为命令行参数
python tests.py                     # 核心算法自检
python tests.py --ui                # 追加 UI 冒烟测试（offscreen）
```

- 打开：Ctrl+O ｜ 保存：Ctrl+S ｜ 重置：Ctrl+R ｜ 对比原图：`\`
- **黑白**：顶栏开关（再点一次恢复彩色）
- **仿制图章**：顶栏开启，Alt+点击 取样源点，左键涂抹，Esc 退出
- **自定义多边形蒙版**：单击依次添加顶点，双击 / 右键 / Enter 完成（至少 3 个点）
- 适合窗口：`0` ｜ 1:1：`1` ｜ 放大/缩小：`+` / `-` ｜ 删除选中取色点：Delete
- 退出蒙版编辑/图章：`Esc`
- 左键拖拽平移（缩放后）、滚轮以光标为中心缩放、双击适应窗口
- 滑块滚轮微调、双击标签（或按右侧“重置”）复位

### AI 接口配置（api.json）

首次启动时会在程序目录创建 `api.json`，并弹出「AI 接口设置」对话框：

1. 填写接口名称、接口 URL（Base URL，例如 `https://example.ai/v1`）与 API Key；
2. 选择接口格式：**OpenAI Chat Completions / OpenAI Responses / Gemini / Anthropic Messages**；
3. 点击 **「拉取模型」**，程序会调用当前接口的 `/models` 获取可用模型并填入下拉框
   （也可以留空让程序自动选择，或手动输入模型名）；
4. 点击保存，配置会自动写入 `api.json`。
5.也可以直接修改配置文件，api.json内已给出一个模板。

之后随时可以点工具栏的 **「AI 接口…」** 修改、添加或删除接口，也可以设置优先使用的接口。
`api.json` 结构如下（API Key 为明文，请勿分享该文件）：

```json
{
  "version": 1,
  "active_id": "a1b2c3d4e5f6",
  "apis": [
    {
      "id": "a1b2c3d4e5f6",
      "name": "我的 OpenAI",
      "protocol": "openai_chat",
      "base_url": "https://example.ai/v1",
      "api_key": "sk-...",
      "model": "gpt-4o",
      "enabled": true
    }
  ]
}
```

说明：AI 接口信息**只从程序目录的 `api.json` 读取**，不会读取环境变量、
本机已开启的本地API接口或自动发现其它模型。若 `api.json` 为空或没有启用的接口，
请先在「AI 接口设置」中添加并保存。

## 2. 功能

| 模块 | 内容 |
| --- | --- |
| 基础 | 曝光(EV)、对比度、高光、阴影、白色、黑色；色温、色调(绿/品红)、饱和度、自然饱和度 |
| 效果 | **清晰度**（中频局部对比）、**降噪**（感知域双边缘滤波，保边去噪）、**锐度**（USM）、**去朦胧**（暗通道雾模型，负值为加雾） |
| 黑白 | 顶栏「黑白」开关：按 Rec.709 亮度混合为灰度，强度由参数驱动，再点一次恢复彩色，方便进行风格化处理或在调色时直观地查看光影  |
| RAW | 安装 `rawpy` 后可直接打开 DNG/CR2/CR3/NEF/ARW/RW2/RAF/ORF 等 RAW（LibRaw 0.22，相机白平衡 + sRGB + AHD 去马赛克，不做预处理，如自动提亮） |
| 曲线 | 可拖拽控制点的 RGB 曲线编辑器：主通道 + R/G/B 四通道，单调三次(PCHIP)插值，背景带直方图；双击加点、右键删点 |
| 颜色分级 | 阴影 / 中间调 / 高光 / 全局 四个色轮，每个带饱和度与亮度滑块，另有“混合”滑块控制过渡柔和度 |
| 取色器 | 点击图像拾取目标颜色 → 自动选中色相 → 色相/饱和度/明亮度滑块只影响该色相范围（带羽化，不影响灰像素）；并预制 **红/橙/黄/绿/青/蓝/紫/洋红** 8 个色相（一排无文字圆形色点，悬停显示颜色名），每个可单独做 ±60° 色相微调（如绿→偏黄/偏青）、影响范围 5~180° |
| 蒙版 | **线性渐变 / 径向渐变 / 画笔 / 自定义多边形** 四种，均可：在画布上直接拖动编辑、设置**羽化**、**反向**（反向=作用于蒙版之外）、画笔可调**笔刷大小**并支持撤销一笔/清除笔迹；**自定义多边形**支持在画面上依次点选任意多个顶点（至少 3 个），自动闭合并填充为多边形，可拖动顶点、右键删除顶点、继续追加顶点；径向渐变把鼠标移到蓝色手柄上会高亮并变为缩放光标，按住拖动即可**缓慢成比例地**改变大小/形状（长轴手柄拉长、短轴手柄压扁，另一个轴保持不变），橙色手柄**旋转**，也可用滑块精确设置半径/长宽比/旋转角；每个蒙版带一整套**局部调整**——基础影调、效果，以及**曲线 / 颜色分级 / 取色器**（右侧面板选中蒙版后，曲线/色轮/取色器分区自动切换为编辑该蒙版的局部参数，取消选中即恢复全局） |
| 仿制图章 | 顶栏开启后 **Alt+点击 取样源点**，左键涂抹即把源区域内容羽化复制到涂抹处（对齐模式：偏移在第一笔确立并持续跟随，Alt+重新取样可重设）；可调笔刷大小、撤销一笔、一键清除全部；修改在调色流水线之前作用于源图，保存自然包含 |
| 自动调色 | 「**自动**」：灰世界白平衡 + 直方图自动色阶，纯本地瞬时、保守可预期；「**AI 调色**」：把降采样图与直方图统计发给视觉大模型，由它返回全套参数（白平衡/影调/曲线/色轮/取色点）并套用到面板。接口配置保存在程序目录的 `api.json`，首次启动会弹出「AI 接口设置」要求填写 Key 与 URL；支持 OpenAI Chat / OpenAI Responses / Gemini / Anthropic 四种格式，可添加多个接口并自动回退。**图像会上传到所选接口**，介意隐私请用「自动」 |

界面：全新的淡蓝灰主题，左侧蓝灰底预览（缩放/平移/取色/蒙版编辑，蒙版以红色半透明叠加显示），右侧为可折叠调整面板——每个模块装在独立的白色毛玻璃托盘里，标题条为浅蓝半透明磨砂质感；顶部工具栏（打开/保存/重置/对比/缩放/取色模式）+ 状态栏。

## 3. 架构

```
FernLens/
├── main.py          入口（首次启动创建 api.json 并提示配置）
├── core.py          全部图像处理：纯 NumPy/OpenCV，输入输出都是 np.ndarray
├── gpu.py           GPU 加速（可选）：OpenCL 融合内核 + 自动回退 CPU
├── auto.py          自动调色：规则版 + AI 版（视觉大模型输出参数）
├── ai_api.py        AI 接口配置（api.json）与四种协议的 HTTP 调用
├── ui_ai_settings.py「AI 接口设置」对话框（增删改、拉取模型）
├── ui_widgets.py    淡蓝灰/毛玻璃主题、滑块/分区/预览/曲线编辑器/色轮控件、后台处理线程
├── ui_window.py     基础/曲线/颜色分级/取色器/蒙版面板 + 主窗口
├── tests.py         核心算法自检 + UI 冒烟测试（python tests.py [--ui]）
├── README.md
└── run.bat          一键启动
```

`core.py` 内部分区（卷标注释可快速定位）：
色彩空间 → 参数模型 → 基础调整 → 曲线 → 颜色分级 → 取色器 → **效果调节** → **蒙版** → 直方图 → 处理流水线。

### 处理流水线（顺序固定，float32 线性光空间）

```
uint8 sRGB → 线性光
  1. 白平衡（色温/色调，几何均值归一化保护曝光）
  2. 基础（曝光 → 对比度 → 高光 → 阴影 → 白色 → 黑色 → 饱和度 → 自然饱和度）
  3. 效果（清晰度 → 降噪 → 锐度 → 去朦胧）
  4. 曲线（主通道 LUT 与 R/G/B LUT 复合后单次查表；默认对角线时短路）
  5. 颜色分级（亮度蒙版 × 零均值色轮偏移，混合滑块控制蒙版锐度）
  6. 蒙版局部调整（各蒙版内做 mini 流水线——基础/效果/曲线/色轮/取色器——后按蒙版混合）
  7. 取色器（色相环形蒙版 × 彩度蒙版；色相旋转/饱和度/明亮度）
→ 裁剪 [0,1] → sRGB → uint8
```

### 实时预览 / 并行处理

- `ui_widgets.ProcessorThread`：独立 QThread 循环取任务；**同一时刻只保留最新一次请求**，
  连续拖动时中间帧被覆盖丢弃，永远不会有任务堆积。
- 参数变化 → 提交 **预览** 任务（最长边 1200px）；松手（`sliderReleased`/曲线松手/笔画结束）
  或空闲 400ms 后 → 提交 **全图** 任务；结果带请求 id 回主线程，过期帧直接丢弃。
- 线性光结果按“数据源”缓存；≥0.6MP 即按行分块并行，线程数 = CPU 逻辑核数（上限 32），
  打开大图时的 sRGB→线性光转换同样分块并行。
- **GPU 加速（可选）**：安装 `pyopencl` 后，纯逐像素阶段（白平衡/基础/黑白/曲线/颜色分级）
  融合为单个 OpenCL 内核在 GPU 上执行（一次上传、一次下载），**NVIDIA / AMD / Intel 显卡
  通用**（GTX/RTX、Radeon、Arc/核显均走同一路径）；效果、蒙版、取色器涉及卷积与
  自定义渲染，自动回退 CPU 多核。无 OpenCL 或运行异常时静默回退，
  环境变量 `FERNLENS_NO_GPU=1` 可强制关闭。测试验证：GTX 1070 上 GPU 与 CPU
  输出最大差 ≤ 2/255。
- **分块无缝的关键**：需要全局信息的算子在整图级别算一次再按行切片复用——
  `LowResRenderer`（清晰度低频图）、`MaskRenderer`（蒙版，先在最长边 768 渲染再上采样）、
  `GlobalStats`（去朦胧的大气光与暗通道平滑半径）；锐度的邻域用 64px halo 重叠，
  降噪按双边滤波半径另计 halo。
  测试验证：含 3 种蒙版 + 3 种效果的 12MP 图，多线程结果与单线程**逐位一致**。
- 并行时把 OpenCV 内部线程限制为 1，避免 N×N 线程互相争抢。
- 实测 12MP（4000×3000）：预览 1200px ≈ 0.25s；全功能全图 ≈ 1~4s（视蒙版数量）；
  27MP 全功能全图 ≈ 7.6s。

## 4. 实现说明 / 取舍

- **线性光空间**：影调/效果/曲线/分级/蒙版都在线性光空间完成；
  取色器的色相/彩度估计、色轮方向向量在感知（sRGB）空间计算。
- **蒙版几何全部归一化**（0..1），因此预览缩放、分块、缓存都不影响定位；
  径向为椭圆（半径 + 长宽比），画笔以笔画点序列存储（支持撤销/清除），
  自定义多边形以顶点序列存储，任意凹多边形均可填充；羽化采用距离变换平滑向内过渡，
  与径向蒙版一致，反向与局部调整自动复用同一套蒙版流水线。
- **曲线**用 Fritsch–Carlson 单调保形三次插值，单调控制点不产生过冲；LUT 复合后单次查表。
- **对比度**：正值用 `smoothstep(smoothstep(v))`（枢轴斜率 2.25、端点趋平），负值用
  `v + 2a·v(1-v)(v-0.5)`（枢轴斜率降到 0.5），两端都保持 0/1 端点与单调性。
- **去朦胧**：暗通道雾模型 `J = (I - A)/t + A`，`t = 1 - 0.85·a·(dark/A)`（A 为亮度 99.9 分位），
  J 裁剪到 [0,1] 后按 |amount| 强度与原图混合，避免暗部被压黑；负值为加雾。
- **降噪**：sRGB 感知域双边缘滤波（bilateral），sigmaColor/sigmaSpace 随强度增长，
  保边去噪；滤波后再转回线性光，流水线中位于清晰度之后、锐度之前（先降噪后锐化）。
- **GPU**：`gpu.py` 把逐像素链融合为一个 OpenCL C 内核，主机侧预计算白平衡增益、
  曲线 LUT（主通道已复合）与色轮偏移向量；缓冲区按尺寸复用，任何异常静默回退 CPU。
- **自动调色**：`auto.py` 只产出参数字典、由同一流水线渲染。规则版反解灰世界增益到
  色温/色调参数并按 70% 力度应用；AI 版把直方图分位数/通道均值/彩度等**测量数据**
  与图像一起发给模型（弥补视觉估计不精），返回的 JSON 经严格钳制（范围、曲线单调化、
  非法字段丢弃）后才应用，全程可撤销（重置即可）。
- **AI 接口**：`ai_api.py` 负责读写 `api.json`、拉取模型和发起请求。请求体按四种格式
  分别组装（Chat 的 `image_url`、Responses 的 `input_image`、Gemini 的 `inline_data`、
  Anthropic 的 `image/source`）；URL 会自动去掉用户误粘贴的完整端点后缀。接口按
  `active_id` 优先、其余按列表顺序回退，单个接口失败不影响后续尝试。
- **取色器只影响彩色像素**：蒙版含彩度权重，中性灰不受影响；重叠区域按蒙版和归一化。
- **色轮方向**为三轴余弦色轮（0°红/120°绿/240°蓝），强度归一化后 |分量| ≤ 1。
- 保存走同一套全图流水线（后台渲染完成后落盘），支持 JPG/PNG/WebP/TIFF，路径支持中文。
- **RAW**：`rawpy` 为可选依赖，未安装时打开对话框不显示 RAW 格式（并给出安装提示）；
  解码使用 `use_camera_wb=True / output_color=sRGB / output_bps=8 / no_auto_bright=True /
  DemosaicAlgorithm.AHD`，暂时未应用 EXIF 方向旋转。
- **可选依赖**：`rawpy`（RAW 解码）与 `pyopencl`（GPU 加速）由 run.bat 自动尝试安装，
  也可手动 `pip install rawpy pyopencl`，失败或未安装均不影响基本功能。
- **仿制图章**：像素级内容修改，在调色流水线之前作用于源图（工作副本 + 笔画列表，
  撤销 = 由原图重放剩余笔画）；盖印为羽化圆盘快照混合，源/目标重叠安全、越界自动裁剪。
- 未来计划加入旋转、裁切、拉直等。敬请期待。
