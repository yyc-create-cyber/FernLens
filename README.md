# PhotoLab — 基于 PySide6 + NumPy + OpenCV 的 Lightroom 风格照片调色器

> **新版（Web/Electron 架构）已可用**：`server.py` + `frontend/`（Vue3）+ `desktop/`（Electron 壳）。
> 调色引擎（core.py/gpu.py/auto.py）与旧版完全共用，输出逐位一致（见 `tests_server.py`）。
>
> - **浏览器模式**：`python server.py --no-auth --port 8642` 后打开 `http://127.0.0.1:8642`
>   （会自动托管 `frontend/dist`；上传打开含 RAW 内存解码、渲染下载）
> - **桌面模式**：双击仓库根目录的 **`package.bat`** 一键打包——自动建环境/装依赖、
>   构建前端、PyInstaller 打服务端、electron-builder 出安装包，完成后把
>   `PhotoLab-Setup-*.exe` 与 `PhotoLab-Portable-*.exe` 复制到桌面；
>   也可手动分步：`cd frontend && npm install && npm run build`，
>   然后 `.venv/Scripts/pyinstaller build/photolab-server.spec --noconfirm --distpath backend-dist`，
>   最后 `cd desktop && npm install && npm run dist` → 产出 `desktop/release/`
>   （原生打开/保存对话框、RAW 支持、自动更新）
> - 架构与实施细节见《PhotoLab-Web化改造方案》（桌面文档），服务端 API 见 `server.py` 模块注释
> - 自检：`python tests.py`（引擎）+ `python tests_server.py`（API 层，含逐位一致验收）

一个纯本地运行的 Windows 照片调色应用：所有调整**实时预览**，处理在后台线程完成，
拖动滑块时处理降采样图（最长边 1200px），松手后自动处理全图。

## 1. 快速开始

```bat
legacy\run.bat         :: 自动建虚拟环境 + 装依赖 + 启动（旧版 PySide6 UI）
```

或手动：

```bash
pip install -r requirements.txt
python legacy\main.py               # 也可把图片路径作为命令行参数
python tests.py                     # 核心算法自检
python tests.py --ui                # 追加 UI 冒烟测试（offscreen）
```

- 打开：Ctrl+O ｜ 保存：Ctrl+S ｜ 重置：Ctrl+R ｜ 对比原图：`\`（也可把图像文件直接拖进窗口打开）
- **历史记录**：右侧「历史」页签列出每一步（含描述与时间），点任意一步即整体回到该状态；Ctrl+Z 撤销 / Ctrl+Shift+Z（或 Ctrl+Y）重做；回退后再调整会从该步开新分支
- **滤镜**：右侧「滤镜」页签点预设即套用；「保存当前」把当前参数存成自己的滤镜，「导出/导入」在滤镜之间搬运 JSON
- **黑白**：顶栏开关（再点一次恢复彩色）
- **仿制图章**：顶栏开启，先拖出**源矩形**（青色框），再在目标处拖出矩形把源内容缩放覆盖过去；Alt+拖动重选源，Esc 退出
- **裁剪/拉直**：顶栏「裁剪」进入，拖动框与 8 个手柄调整，可锁定比例、±45° 拉直（实时预览旋转）；Enter 应用，Esc 取消；「左转90°/右转90°」立即应用
- 适合窗口：`0` ｜ 1:1：`1` ｜ 放大/缩小：`+` / `-` ｜ 删除选中取色点：Delete
- 退出蒙版编辑/图章：`Esc`
- 左键拖拽平移（缩放后）、滚轮以光标为中心缩放、双击适应窗口
- 滑块滚轮微调、双击标签（或按右侧“重置”）复位

## 2. 功能

| 模块 | 内容 |
| --- | --- |
| 基础 | 曝光(EV)、对比度、高光、阴影、白色、黑色；色温、色调(绿/品红)、饱和度、自然饱和度 |
| 效果 | **清晰度**（中频局部对比）、**降噪**（感知域亮色分离：色度一遍重滤去色斑；亮度三遍轻滤压噪声，再按「结构权重」回注高频——同号聚集的真结构回注 0.35，散乱噪声只回注 0.1~0.9，平坦区干净、纹理不发“肉”）、**锐度**（USM）、**去朦胧**（暗通道雾模型，负值为加雾） |
| 黑白 | 顶栏「黑白」开关：按 Rec.709 亮度混合为灰度，强度由参数驱动，再点一次恢复彩色，方便进行风格化处理或在调色时直观地查看光影  |
| RAW | 安装 `rawpy` 后可直接打开 DNG/CR2/CR3/NEF/ARW/RW2/RAF/ORF 等 RAW（LibRaw 0.22，相机白平衡 + sRGB + AHD 去马赛克，不做预处理，如自动提亮） |
| 曲线 | 可拖拽控制点的 RGB 曲线编辑器：主通道 + R/G/B 四通道，单调三次(PCHIP)插值，背景带直方图；双击加点、右键删点 |
| 颜色分级 | 阴影 / 中间调 / 高光 / 全局 四个色轮，每个带饱和度与亮度滑块，另有“混合”滑块控制过渡柔和度 |
| 取色器 | 点击图像拾取目标颜色 → 自动选中色相 → 色相/饱和度/明亮度滑块只影响该色相范围（带羽化，不影响灰像素）；并预制 **红/橙/黄/绿/青/蓝/紫/洋红** 8 个色相，每个可单独做 ±60° 色相微调（如绿→偏黄/偏青）、影响范围 5~180° |
| 滤镜 | 内置 14 个预设（原图 / 通透 / 柔光 / 浓郁 / 暖阳 / 冷调 / 柔肤人像 / 清透风光 / 复古胶片 / 电影青橙 / 日系清透 / 夜景霓虹 / 经典黑白 / 高反差黑白），点一下即套用；「保存当前」把当前参数存成自定义滤镜（localStorage 持久化），「导出 / 导入」用 JSON 搬运。**滤镜只含基础内容**：全局影调 + 效果四件套 + 曲线 + 分级色轮；**不含**蒙版（含 AI 识别蒙版）、取色点、仿制图章、裁剪/旋转、局部调整与历史记录——面板顶部有同样的说明。套用后在「历史」里记一步「滤镜 · 名字」，可撤销或跳回 |
| 蒙版 | **线性渐变 / 径向渐变 / 画笔 / AI 识别** 四种。线性渐变除拖动三条端线外，终点外侧还有**橙色旋转手柄**（拖动绕中线中心旋转，Shift 吸附 15°），面板有**角度滑块（0..360°）**与「↺/↻ 15°」按钮，选中后 **Q/E 键微调 ±1°（Shift ±15°）**——旋转保持渐变长度与中心不变，端点可延伸出画布。AI 识别为 LR 式「选择主体 / 人物 / 背景 / 天空」：**全部本地推理**（SAM 2.1 + U²-Net + SkySeg + YOLOv8n，onnxruntime），图像不出本机、不调用任何云端接口；模型随安装包内置（约 575MB），缺失时首次使用从 hf-mirror 下载。输出为像素级掩码，可直接在右侧做局部调整，裁剪/旋转时按同一映射重采样重定位（裁剪不产生空洞；90° 旋转时掩码随图像转置）。线性/径向/画笔可设置**羽化**；四种蒙版均可设置**反向**（反向=作用于蒙版之外）、画笔可调**笔刷大小**并支持撤销一笔/清除笔迹；径向渐变把鼠标移到蓝色手柄上会高亮并变为缩放光标，按住拖动即可**缓慢成比例地**改变大小/形状（长轴手柄拉长、短轴手柄压扁，另一个轴保持不变），橙色手柄**旋转**，也可用滑块精确设置半径/长宽比/旋转角；每个蒙版带一整套**局部调整**——基础影调、效果，以及**曲线 / 颜色分级 / 取色器**（右侧面板选中蒙版后，曲线/色轮/取色器分区自动切换为编辑该蒙版的局部参数，取消选中即恢复全局） |
| 仿制图章 | 顶栏开启后**两步走**：① 在图像上拖出**源矩形**（青色虚线框常驻显示）；② 在目标处拖出目标矩形，源区域内容即**缩放覆盖**过去（边缘羽化可调，源/目标大小可不同）。可连续覆盖多处、撤销一次、清除全部；Alt+拖动或「重选源区」重新取样；修改在调色流水线之前作用于源图，保存自然包含 |
| 裁剪/旋转 | 顶栏「**裁剪**」：画布上拖动裁剪框（8 手柄/移动/三分网格/框外压暗），比例锁定（自由/原始/1:1/3:2/4:3/16:9 及转置），**拉直 ±45°** 实时旋转预览且裁剪框自动约束在有效区；「**左转90°/右转90°**」一步到位。蒙版坐标随几何变换**精确同步**（角度/中心/半径），图章修改一并并入源图 |
| 自动调色 | 「**自动**」：灰世界白平衡 + 直方图自动色阶，纯本地瞬时、保守可预期；「**AI 精修**」：把图像压缩后（最长边 1280、JPEG 90，超 2MB 自动再压）连同亮度/色彩统计发给视觉大模型，按「克制、保留原片质感」的提示词返回全套参数（白平衡/影调/曲线/色轮/取色点）JSON，再按「AI 设置」里的**调整强度**（默认 60%）统一缩放后套用到面板，避免过度后期；可填**精修要求**（如“暖调黄昏电影感”“日系胶片”），留空则由模型自选风格。端点在顶栏「**AI 设置**」中配置（URL / API Key / 模型 ID，任意 OpenAI 兼容接口），也可用环境变量 `PHOTOLAB_AI_BASE_URL / PHOTOLAB_AI_KEY / PHOTOLAB_AI_MODEL` 后备；**图像会上传到该端点**，介意隐私请用「自动」 |

界面：左侧深灰底预览（缩放/平移/取色/蒙版编辑，蒙版以红色半透明叠加显示），右侧可折叠调整面板，顶部工具栏（打开/保存/重置/对比/缩放/取色模式）+ 状态栏。

### 滤镜 JSON 格式

单个滤镜导出的样子（「导出」只选一个时就是这个结构）：

```json
{
  "format": "photolab-filter",
  "version": 1,
  "name": "暖阳",
  "createdAt": "2026-11-12T10:41:00.000Z",
  "look": {
    "temperature": 24,
    "tint": 6,
    "exposure": 0.14,
    "curves": { "master": [[0, 0], [0.25, 0.22], [0.75, 0.78], [1, 1]] },
    "wheels": { "shadows": { "hue": 220, "saturation": 14, "luminance": 0 } }
  }
}
```

- `look` 里所有字段都可省略，只覆盖出现的字段（影调 15 项、`curves`、`wheels`）；越界数值自动夹到合法范围（曝光 −5..5 EV，黑白 0..100，其余 −100..100）。
- 导入还接受 `[ ... ]` 数组、`{ "filters": [ ... ] }`（「导出」全部时即此结构），以及直接把一份 `Adjustments` 参数当作 `look`。
- 曲线每通道为 `[[x, y], ...]`，x/y ∈ 0..1；端点会被规整到 x=0 与 x=1。
- 蒙版与取色点不会写入滤镜：前者是单张照片的几何，后者颜色取自具体画面。

## 3. 架构

```
photolab/
├── core.py          全部图像处理：纯 NumPy/OpenCV，输入输出都是 np.ndarray（新旧版共用，冻结）
├── gpu.py           GPU 加速（可选）：OpenCL 融合内核 + 自动回退 CPU
├── auto.py          自动调色 + AI 精修：规则版 + 视觉大模型（克制型参数调色，按强度缩放）
├── server.py        新版 Web 后端：FastAPI，把 core 流水线暴露为 REST + WebSocket（见模块注释）
├── tests_server.py  服务端 API 自检（含与 core.process 逐位一致验收）
├── tests.py         核心算法自检 + 旧 UI 冒烟测试（python tests.py [--ui]）
├── legacy/          旧版 PySide6 UI（main.py / ui_window.py / ui_widgets.py / run.bat）
├── frontend/        新版 Web UI：Vue3 + TypeScript + Naive UI（Canvas 视口/曲线/色轮/蒙版编辑）
├── desktop/         Electron 壳：sidecar 拉起、原生对话框、electron-builder 打包与自动更新
├── build/           打包资产：应用图标 + PyInstaller spec
├── docs/            架构改造方案文档
├── backend-dist/    sidecar 打包产物（本地产物，不入库）
└── README.md
```

- **新版快速入口**：见文件顶部说明（浏览器模式 / 桌面打包）
- **旧版 PySide6 UI**：`legacy\run.bat` 一键启动（引擎同 core.py，保留至新版功能完全对齐后移除）

`core.py` 内部分区（卷标注释可快速定位）：
色彩空间 → 参数模型 → 基础调整 → 曲线 → 颜色分级 → 取色器 → **效果调节** → **蒙版** → **仿制图章/几何变换** → 直方图 → 处理流水线。

### 处理流水线（顺序固定，float32 线性光空间）

```
uint8 sRGB → 线性光
  1. 白平衡（色温/色调，几何均值归一化保护曝光）
  2. 基础（曝光 → 对比度 → 高光 → 阴影 → 白色 → 黑色 → 饱和度 → 自然饱和度）
  3. 效果（清晰度 → 降噪 → 锐度 → 去朦胧）
  4. 曲线（主通道 LUT 与 R/G/B LUT 复合后单次查表；默认对角线时短路）
  5. 颜色分级（亮度蒙版 × 零均值色轮偏移，混合滑块控制蒙版锐度）
  6. 蒙版局部调整（各蒙版内做 mini 流水线——基础/效果/曲线/色轮/取色器——后按蒙版混合）
  7. 取色器（色相环形蒙版 × 彩度蒙版；色相旋转/饱和度/明亮度）
→ 裁剪 [0,1] → sRGB → uint8
```

### 实时预览 / 并行处理

- `ui_widgets.ProcessorThread`：独立 QThread 循环取任务；**普通任务同一时刻只保留最新一次请求**，
  连续拖动时中间帧被覆盖丢弃，永远不会有任务堆积；**保存走独立紧急槽位**，
  不会被随后的参数更新覆盖；关闭窗口时正在渲染的任务**协作取消**（分块之间检查），
  线程及时退出、不会在进程收尾时崩溃。
- 拖动中提交**草稿**任务（视口长边的 0.62 倍），松手/空闲 400ms 提交**全尺寸**任务。
  草稿帧分辨率更低，但**按同一矩形拉伸显示**（`store.geomW/geomH` 取最近一帧全尺寸结果），
  所以画面不会在草稿帧到达时突然缩小、松手后再跳回去（缩放时尤其明显）。
- 参数变化 → 提交 **预览** 任务（最长边 1200px）；松手（`sliderReleased`/曲线松手/笔画结束）
  或空闲 400ms 后 → 提交 **全图** 任务；结果带请求 id 回主线程，过期帧直接丢弃。
- 线性光结果按“数据源”缓存；≥0.12MP 即按行分块并行，块数按参数自适应：
  **含清晰度/降噪/锐化/去朦胧时用 2 块**（这些算子靠 OpenCV 内部并行，块多了 halo
  重复计算与线程争抢反而更慢，实测 8 块比 1 块慢 1.5 倍），**纯逐像素链用 8 块**。
  打开大图时的 sRGB→线性光转换同样分块并行。
- **GPU 加速（可选）**：安装 `pyopencl` 后，纯逐像素阶段（白平衡/基础/黑白/曲线/颜色分级）
  融合为单个 OpenCL 内核在 GPU 上执行（一次上传、一次下载），**NVIDIA / AMD / Intel 显卡
  通用**（GTX/RTX、Radeon、Arc/核显均走同一路径）；效果、蒙版、取色器涉及卷积与
  自定义渲染，自动回退 CPU 多核。无 OpenCL 或运行异常时静默回退，
  环境变量 `PHOTOLAB_NO_GPU=1` 可强制关闭。测试验证：GTX 1070 上 GPU 与 CPU
  输出最大差 ≤ 2/255。
- **GPU 只做基础影调**：效果算子（清晰度/降噪/锐化/去朦胧）必须在 CPU 上按块跑，
  但它们的**输入**是基础影调结果。这条路径用 `basic_frame` 内核把
  「白平衡 + 曝光 + 对比度 + 高光/阴影/白色/黑色 + 饱和度/自然饱和度」整幅算完
  （输出 float32 线性光，不编码），CPU 只接着算效果/曲线/分级/蒙版。
  与 CPU 版 `apply_basic` 共用同一份设备函数实现，逐阶段差异仅来自
  对比度查表量化（≤4e-5），端到端 8 位差 ≤ 2/255，耗时降 10%~40%
  （0.96MP 全链 984ms → 588ms，本机 Intel UHD 核显）。
- **分块无缝的关键**：需要全局信息的算子在整图级别算一次再按行切片复用——
  `LowResRenderer`（清晰度低频图）、`MaskRenderer`（蒙版，先在最长边 768 渲染再上采样）、
  `GlobalStats`（去朦胧的大气光与暗通道平滑半径）；锐度的邻域用 64px halo 重叠，
  降噪按双边滤波半径×3 遍另计 halo（三遍串起来影响半径更大，按 3σ 计）。
  测试验证：含 3 种蒙版 + 3 种效果的 12MP 图，多线程结果与单线程**逐位一致**。
- 并行时按块数分配 OpenCV 内部线程（重效果 2 块 × 4 线程、纯像素链 8 块 × 1 线程），
  避免 N×N 线程互相争抢。
- **查表化**：sRGB 编解码、曲线、对比度、降噪的 gamma 域转换都改成 16 位量化查表
  （`cv2.LUT`），量化误差 ≤ 4e-5（远小于 1/255），逐点 `np.power` 从 20~56ms 降到 3~13ms；
  曲线表与 GPU 内核共用同一张编码表，GPU 预览与 CPU 保存仍逐位一致。
- **饱和/自然饱和度合并**：两段都是「绕亮度线性缩放色度」，而亮度是通道线性组合、
  缩放后不变，所以第二段的色度权重可由缩放前的极值直接推出
  （`apply_saturation_vibrance`）。省掉 3 次整幅读写（0.96MP 80ms → 59ms），
  浮点差 ≤ 1 ULP（8 位输出无差别）。
- 实测 12MP（4000×3000）：预览 1200px ≈ 0.25s；全功能全图 ≈ 1~4s（视蒙版数量）；
  27MP 全功能全图 ≈ 7.6s。单帧耗时（i5 低压 15W 8 逻辑核，峰值参数）：
  0.37MP 全链 199ms、0.96MP 全链 541ms，比优化前快 1.2~1.5 倍。

## 4. 实现说明 / 取舍

- **线性光空间**：影调/效果/曲线/分级/蒙版都在线性光空间完成；
  取色器的色相/彩度估计、色轮方向向量在感知（sRGB）空间计算。
- **蒙版几何全部归一化**（0..1），因此预览缩放、分块、缓存都不影响定位；
  径向为椭圆（半径 + 长宽比），画笔以笔画点序列存储（支持撤销/清除）。
- **曲线**用 Fritsch–Carlson 单调保形三次插值，单调控制点不产生过冲；LUT 复合后单次查表。
- **对比度**：正值用 `smoothstep(smoothstep(v))`（枢轴斜率 2.25、端点趋平），负值用
  `v + 2a·v(1-v)(v-0.5)`（枢轴斜率降到 0.5），两端都保持 0/1 端点与单调性。
- **去朦胧**：暗通道雾模型 `J = (I - A)/t + A`，`t = 1 - 0.85·a·(dark/A)`（A 为亮度 99.9 分位），
  J 裁剪到 [0,1] 后按 |amount| 强度与原图混合，避免暗部被压黑；负值为加雾。
- **降噪**：sRGB 感知域双边缘滤波（bilateral），sigmaColor/sigmaSpace 随强度增长，
  保边去噪；滤波后再转回线性光，流水线中位于清晰度之后、锐度之前（先降噪后锐化）。
  亮度与色度分开处理：色度一遍大 sigma 滤净色斑；亮度三遍小半径轻滤（等效支持域够大，
  但中低对比纹理每遍都低于 sigmaColor 而保住），随后把被滤掉的亮度高频按结构权重回注。
  结构判定用「高频在 3px 尺度上是否同号聚集」（噪声零均值，平滑后趋零），阈值取整幅图
  噪声基线的 1.2~4.2 倍（`GlobalStats.noise_ref`，384px 缩略图估计，分块共用同一值，
  否则接缝处会出现横条）。
  实测（900px 真实照片 + 合成噪声 σ=12/255）：强度 60 时平坦区残余噪声 −26%、
  纹理相关度 0.60 → 0.71；强度 100 时 −43%、0.79 → 0.89。代价是耗时约为旧实现的 3 倍
  （0.37MP 单效果 250ms），换来的是高感画面不发“塑料”。
- **GPU**：`gpu.py` 把逐像素链融合为一个 OpenCL C 内核，主机侧预计算白平衡增益、
  曲线 LUT（主通道已复合）与色轮偏移向量；缓冲区按尺寸复用，任何异常静默回退 CPU。
- **自动调色**：`auto.py` 只产出参数字典、由同一流水线渲染。规则版反解灰世界增益到
  色温/色调参数并按 70% 力度应用；AI 版先把图像压缩（最长边 1280、JPEG 90，
  超过 2 MB 自动降尺寸/质量）再与直方图分位数/通道均值/彩度等**测量数据**一起
  发给模型，提示词要求**克制**：只做必要修正 + 轻微风格化，常规项 5~20、关键项
  25~35、极少超过 40，同一影调区间不叠加多种手段（并支持用户填写的精修要求）；
  返回的 JSON 先经严格钳制（范围、曲线单调化、非法字段丢弃、缩放后退化成对角线的
  曲线直接丢弃），再按 **AI 调整强度**（默认 60%，可在「AI 设置」里 20%~100% 调）
  统一缩放标量/曲线/色轮/取色器的幅度，色相不变，因此模型给得再猛也不会一键过度
  后期。全程可撤销（重置即可）。
  端点配置：前端「AI 设置」分**两套** OpenAI 兼容端点（各自 URL / API Key / 模型 ID，
  localStorage 持久化）——
  1. **对话模型**：讨论(1)、参数(2)、一键精修；服务端 `/api/auto` 收到的是这套配置，
     环境变量 `PHOTOLAB_AI_BASE_URL / PHOTOLAB_AI_KEY / PHOTOLAB_AI_MODEL` 作后备；
  2. **图生图模型**：生图(3)，前端直连 `/images/edits`，与对话模型可以不同厂商、不同 Key。
  每套端点各有一个「测试连接」= GET `{base}/models`，可顺带拉取模型列表补全模型 ID。
  旧版单端点配置（含 `imageModel` 复用）在首次加载时自动迁移成两套。
- **AI 蒙版**：只用本地像素级引擎（`segment.py` 的 SAM 2.1 + U²-Net ONNX 推理），
  图像不出本机、不消耗 API；输出 base64 PNG 概率图存入 `MaskState(kind='ai')`（旧文档
  里的网格蒙版仍可读取渲染）。渲染 = 概率图双线性放大后收紧边界（AI 蒙版
  **不羽化**，识别到哪就作用到哪，避免局部调整渗到背景）；裁剪/旋转时按同一归一化映射前向重采样。蒙版低分辨率
  渲染走跨任务 LRU（几何未变直接复用，拖滑块时不再重复渲染蒙版），命中结果与
  首次逐位一致。画面中未识别到目标（如无人/无天空）返回 400 并提示，不产生空蒙版。
- **多图导入**：打开对话框支持一次多选（浏览器 `multiple` / Electron
  `multiSelections`），每张图入服务端图库（独立 Document：源图/图章/几何互不影响）；
  视口底部胶片条显示缩略图，点击切换，每张图**独立保存全套调色参数**（前端随切换
  暂存/恢复），✕ 移除（删当前图自动切到相邻）；刷新页面后图库自动恢复（参数不保）。
- **取色器只影响彩色像素**：蒙版含彩度权重，中性灰不受影响；重叠区域按蒙版和归一化。
- **色轮方向**为三轴余弦色轮（0°红/120°绿/240°蓝），强度归一化后 |分量| ≤ 1。
- 保存走同一套全图流水线（后台渲染完成后落盘），支持 JPG/PNG/WebP/TIFF，路径支持中文。
- **RAW**：`rawpy` 为可选依赖，未安装时打开对话框不显示 RAW 格式（并给出安装提示）；
  解码使用 `use_camera_wb=True / output_color=sRGB / output_bps=8 / no_auto_bright=True /
  DemosaicAlgorithm.AHD`，暂时未应用 EXIF 方向旋转。
- **可选依赖**：`rawpy`（RAW 解码）与 `pyopencl`（GPU 加速）由 run.bat 自动尝试安装，
  也可手动 `pip install rawpy pyopencl`，失败或未安装均不影响基本功能。
- **仿制图章**：像素级内容修改，在调色流水线之前作用于源图（工作副本 + 覆盖操作列表，
  撤销 = 由原图重放剩余操作）。每次覆盖 = 源矩形双线性缩放到目标矩形后按羽化 alpha 混合，
  源/目标重叠安全、越界自动裁剪；源矩形与目标矩形均以归一化坐标存储。
- **裁剪/旋转**：与图章同层，在流水线之前直接改写源图。90° 旋转无损（数组转置）；
  拉直 = 绕中心双线性旋转（画布不变）后把裁剪框约束在有效区（二分收缩到四角都落在
  原图内）；蒙版坐标按同一仿射精确同步（线性端点/径向中心与角度/画笔轨迹，半径按
  短边像素比缩放）。应用几何变换时已有图章笔画并入源图（此后不再逐步撤销）。
- 未来计划加入更多蒙版与笔刷。敬请期待。

## 5. 桌面版与跨平台

### Windows

```bat
package.bat
```

产物在 `desktop\release\`：`PhotoLab-Setup-<version>.exe`（安装版）与
`PhotoLab-Portable-<version>.exe`（便携版）。

### macOS

**必须在 Mac 上打包**：PyInstaller 不能交叉编译，sidecar 必须是本机 Mach-O 二进制；
dmg 与 codesign 也依赖 macOS 自带工具。Windows 上现成的 `.exe` 在 macOS 上无法运行。

```bash
chmod +x package.command
./package.command
```

产物：`desktop/release/PhotoLab-Setup-<version>-<arch>.dmg` 与同名 `.zip`。

- **架构**：一次只出一种架构（PyInstaller 产物是单架构）。Apple Silicon 与 Intel 需分别打包，
  或直接用仓库里的 `.github/workflows/mac.yml`（GitHub Actions 手动触发，macOS 双架构矩阵），
  在 Actions 页面的 Artifacts 里下载 dmg，不需要自己的 Mac。
- **首次打开**：未签名发行会提示「无法验证开发者」——右键 →「打开」，或
  `xattr -dr com.apple.quarantine /Applications/PhotoLab.app`。想去掉提示需 Apple Developer ID
  签名 + 公证（`mac.hardenedRuntime=true`、`build/entitlements.mac.plist` 已备好）。
- **GPU**：macOS 的 OpenCL 已被 Apple 标记为废弃但仍可用；初始化失败会静默回退 CPU，
  画面与 GPU 路径一致（仅速度不同）。`PHOTOLAB_NO_GPU=1` 可强制关闭。
- **本地蒙版**：`onnxruntime` 的 macOS 轮子含 arm64，SAM 2.1 / U²-Net 模型随包内置；
  若打包时 `models/` 不存在则首次使用会从 hf-mirror 下载。
- **快捷键**：macOS 上自动挂载应用菜单（⌘C/⌘V/⌘Z/⌘Q 等系统快捷键依赖菜单注册），
  关闭窗口不退出应用，⌘Q 退出。
